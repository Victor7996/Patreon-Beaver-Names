Names your newborn beavers after your Patreon supporters — in order, every time.

Connect to the Patreon API with your Creator Access Token and the mod fetches your active supporters automatically. Each beaver born gets the next name on the list. When the list runs out, it loops. The position is saved with your game so no name is ever skipped between sessions.

No Patreon account? Drop names into the included [code]patreons.csv[/code] file instead — one name per line, works fully offline.

[hr][/hr]

[h1]What it does[/h1]
[list]
    [*]Assigns the next supporter name to every newborn beaver, in sequence
    [*]Saves the current position in your save file — survives reloads and restarts
    [*]Fetches live from Patreon API v2 using your Creator Access Token
    [*]Auto-discovers your Campaign ID — just paste your token and you're done
    [*]Filters by tier: toggle Bronze, Silver, Gold, and custom tiers independently
    [*]Handles large campaigns with full pagination and rate limit backoff
    [*]Falls back to a local CSV file if no token is configured
[/list]

[hr][/hr]

[h1]Optional: Mod Settings[/h1]
Works without it — configure via [code]patreons.csv[/code]. With [url=https://mod.io/g/timberborn/m/modsettings]Mod Settings[/url] installed you get a full in-game panel:
[list]
    [*]Paste your Creator Access Token directly in-game
    [*]Set or auto-detect your Campaign ID
    [*]Toggle tiers (Bronze / Silver / Gold / Custom) with checkboxes
    [*]Live preview of the loaded name list, updated after each API fetch
[/list]
